# Project Instructions

## Markdown Table Compatibility (Obsidian)

To ensure tables render correctly in Obsidian, always follow this format:

| Feature | Syntax |
| :--- | :--- |
| **Leading/Trailing Pipes** | Always include `|` at the start and end of each row. |
| **Separator Row** | Use at least three dashes `---` and colons `:` for alignment. |
| **No Empty Lines** | Ensure there are no empty lines between any rows of the table. |
| **Escaping Pipes** | Use `\|` for pipes inside cells, especially for wikilink aliases: `[[Note\|Alias]]`. |

### Example

| Category | Item | Description |
| :--- | :---: | ---: |
| Software | Obsidian | A powerful knowledge base |
| Format | Markdown | Simple text-based formatting |
| Link | [[Note\|Alias]] | Wikilink with an alias |
